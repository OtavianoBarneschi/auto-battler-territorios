# Limitações e decisões V.05

- São estudos para escolha, não um redesign aprovado da coleção. Só Cowboy e Rádio são exibidos no ateliê.
- A linguagem compacta de habilidade cobre início de combate com dano ao primeiro/último inimigo. Outras habilidades exigirão estudo após aprovação.
- A base não define custo individual; nenhum custo foi inventado. Rank aparece com raridade.
- Na visão geral de celular, detalhes pequenos devem ser vistos usando os filtros A–E para ampliar.
- Sem persistência de favorito ou botão que aplique um modelo ao jogo: a aprovação será dada pelo usuário na conversa.
- Limitações herdadas do jogo V.04: recarregar reinicia partida, BOT heurístico, comportamento de arrasto dependente do navegador.
- CLI Cloudflare sem autenticação nesta sessão; publicação confirmada pela integração Git existente. Evidências em AUDITORIA.md.
